Base científica revisada por pares

Este engine recebe tipos de dado disponíveis em um schema e calcula quais inferências estatísticas são viáveis, com cobertura ponderada pelos pesos da literatura científica original. Não gera confiança inventada — o percentual exibido é a fração das variáveis do estudo de referência que o usuário possui.

Cada modelo mapeia para um estudo publicado, revisado por pares. Os pesos vêm de coeficientes β (Cox), pontos de score (FINDRISC), importância relativa reportada (RFM) ou GINI incremental (credit scoring). Onde a base científica é fraca ou os dados exigem cuidado ético, isso é declarado explicitamente no caveat de cada modelo.

Arquitetura de níveis

N1 Inferências primárias — calculadas diretamente dos dados brutos. Cada modelo N1 mapeia para um estudo publicado com variáveis e pesos conhecidos.
N2 Inferências compostas — combinam dois ou mais modelos N1 já calculados. Requerem cobertura mínima nas inferências de entrada.
N3 Meta-inferências — combinam modelos N2. Representam visões integradas e acumulam as incertezas de todos os níveis anteriores.

Uso responsável e conformidade

Dados de fenotipagem digital (GPS passivo, HRV via wearable, velocidade de digitação, sono passivo) requerem consentimento informado explícito e base legal sob a LGPD (Lei 13.709/2018), preferencialmente consentimento (Art. 7º, I) ou legítimo interesse documentado com análise de impacto (Art. 7º, IX). O tratamento de dados de saúde se enquadra no Art. 11º da LGPD, que exige requisitos adicionais.

Inferências de saúde mental são triagens populacionais, nunca diagnósticos individuais. A maioria dos estudos de base tem n<100, amostras universitárias e risco de viés de publicação documentado. Resultados não substituem avaliação clínica por profissional habilitado.

Inferências de crédito e financeiras têm regulação específica: Resolução CMN 4.966/2021 (comprometimento de renda), Lei do Cadastro Positivo (Lei 12.414/2011), e Resolução CMN 4.557/2017 (gestão de riscos). O uso em decisões automatizadas pode enquadrar o sistema como sistema de pontuação creditícia (Art. 5º, Lei 12.414/2011).

§0 Formulação matemática

Cobertura ponderada: a inovação central do engine
Cobertura de modelo — N1
Cm = Σi ∈ S wiΣi ∈ Vm wi
Cmcobertura do modelo m, no intervalo [0, 1]
Vmconjunto completo de variáveis do modelo m no estudo de referência
Ssubconjunto de variáveis de Vm disponíveis no schema do usuário (S ⊆ Vm)
wipeso da variável i, derivado da literatura original do modelo, não arbitrário

Origem dos pesos wi

Os pesos não são atribuídos arbitrariamente. Cada wi é derivado de uma das seguintes fontes, dependendo do modelo:

Coeficientes β (Cox) Framingham — wpressão = 28%, wcolesterol = 22%
Pontos do score original FINDRISC — hist. glicemia = 5 pts → w = 25%
Feature importance (XGBoost/SHAP) RFM — recência = maior variância → w = 38%
GINI incremental Credit scoring — score = ΔGINI +0,15 → w = 34%
Correlação r com desfecho GPS-depressão — distância: r=−0,25 → w = 25%

Os pesos dentro de cada modelo somam 100%. Variáveis do estudo original sem equivalente no schema recebem wi = 0 na soma do numerador, mas continuam no denominador — reduzindo a cobertura.

Por que cobertura e não confiança?

A diferença é epistemológica, não apenas semântica. Uma confiança implica que o sistema sabe quão correto está. A cobertura afirma apenas o que o sistema sabe: qual fração das evidências necessárias está presente.

Pseudo-confiança (rejeitada) Cobertura ponderada (adotada)
Fórmula arbitrária: base + Σ(gain × matched/total) Cm = Σwi∈S / Σwi∈Vm
Pesos inventados pelo sistema Pesos derivados da literatura publicada
Implica precisão do output Declara completude do input
Gênero com qualquer dado → 70% Gênero sem sexo declarado → 8% (só nome)

Cobertura para inferências compostas — N2 e N3

Modelos compostos não recebem dados brutos diretamente. Eles recebem como entrada as coberturas das inferências N1 (ou N2) que os alimentam, ponderadas pelo peso relativo de cada inferência na composição:

Cn2 = Σk ∈ A φk · CkΣk ∈ A φk
Cn2cobertura da inferência composta
Asubconjunto de inferências N1 necessárias que estão ativas (cobertura > 0)
φkpeso da inferência N1 de id k na composição do modelo N2 — derivado da literatura do modelo composto
Ckcobertura calculada da inferência N1 de id k, conforme a fórmula acima

O denominador usa apenas as inferências em A (ativas), não o conjunto completo de entradas possíveis do modelo. Isso evita penalizar artificialmente modelos N2 quando algumas de suas entradas N1 sequer são relevantes para o schema disponível. N3 aplica a mesma fórmula substituindo Ck por coberturas de modelos N2.

Exemplo numérico — Risco cardiovascular (Framingham)

Dado um schema com: Pressão arterial, Tabagismo e Diabetes. Ausentes: Colesterol, Idade, Anti-hipertensivo.

Interpretação correta: "O usuário possui 56% do peso das evidências que o estudo Framingham (2008) considera relevantes para calcular o risco cardiovascular." Não: "O sistema tem 56% de confiança de que o risco está correto." As duas afirmações têm implicações radicalmente diferentes para uso responsável.

Propriedades formais

Completude Se S = Vm, então Cm = 1. Com todos os dados do estudo original, cobertura é máxima.
Monotonicidade Adicionar qualquer variável de Vm ao schema nunca reduz Cm. A cobertura é não-decrescente com dados.
Ponderação Adicionar uma variável de alto peso (ex.: pressão no Framingham, w=28%) aumenta mais Cm que uma de baixo peso (ex.: anti-hipertensivo, w=8%).
Limitação Cm não é uma probabilidade. Não estima a chance de o output estar correto — apenas a fração do input do modelo original que está disponível.

Limiar de ativação

Um modelo só é exibido se Cm ≥ 0,05 (5%). Abaixo disso, a cobertura é considerada insuficiente para qualquer inferência útil — mesmo que tecnicamente calculável.

Para modelos N2 e N3, é exigida adicionalmente a presença de pelo menos min inferências N1 ativas (definido por modelo, tipicamente 2). Isso evita que um modelo composto apareça com base em uma única inferência de entrada.

Desbloqueios de tela/dia
Feno		 Frequência de desbloqueios — correlaciona com depressão Triagem de depressão Correlação positiva com depressão: mais desbloqueios = mais sintomas (Saeb et al. 2015). Interpretação: busca de distração ou reforço negativo.
Uso noturno (após 22h)
Feno		 Uso após 22h — proxy de cronotipo e solidão Triagem de ansiedade Cronotipo noturno: piores índices de ansiedade, depressão e sono. Solidão severa: uso do teclado significativamente maior durante horário de sono (Biomedical Eng. Letters 2024).
Velocidade de digitação
Feno		 WPM médio em teclado virtual — reduzida em depressão Triagem de depressão Lentificação prediz PHQ-9 e função cognitiva em mood disorders (BiAffect keyboard, PMC12412914, 2025, n=127). Retardo psicomotor reflete-se na cadência de digitação.
HRV (variabilidade cardíaca)
Feno		 Variabilidade entre batimentos via wearable Triagem de ansiedade, Risco episódio de humor Deep learning com HRV 5 min: 83% acurácia para ansiedade (Nath et al. 2020, n=652). HRV reduzida em TAG vs controles (Tomasi et al. 2024, n=240, CAMH). Confundidores: idade, medicação, condicionamento.
Passos/dia (acelerômetro)
Feno		 Contagem passiva via sensor Triagem de depressão, Triagem de ansiedade, Risco episódio de humor Atividade motora reduzida em depressão; aumentada em mania — padrão invertido permite discriminar tipo de episódio (PMC10753422, revisão sistemática).
Contatos Bluetooth/dia
Feno		 Dispositivos únicos detectados — proxy de interação social presencial Risco episódio de humor Redução de interações presenciais: sinal de episódio depressivo iminente (PMC10753422). Estudado principalmente em contexto hospitalar — generalização para ambulatorial é limitada.
Sono via wearable
Feno		 Duração, eficiência e fase do sono medidas passivamente Triagem de ansiedade, Risco episódio de humor Feature mais importante do modelo Nour 2024: fase atrasada = episódio depressivo; fase adiantada = episódio maníaco. AUC=0,80/0,98/0,95 para dep/mania/hipomania (n=168, 587 dias).
